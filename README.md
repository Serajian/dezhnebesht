# دژنبشت

دانشنامهٔ شخصی. ایستا، بدون وابستگی، دوزبانه (فارسی/انگلیسی).

نام از `diz ī nibišt` پهلوی می‌آید — «دژِ نوشته‌ها»، آرشیوی که در روایت ساسانی نسخه‌ای از اوستا در آن نگهداری می‌شد.

محتوا به **موضوع** تقسیم می‌شود و هر موضوع دسته‌ها و مدخل‌های خودش را دارد.

## اجرا

`fetch()` روی `file://` کار نمی‌کند، پس باز کردن مستقیم `index.html` صفحهٔ خالی می‌دهد. حتماً سرو کنید:

```bash
node serve.js
```

سپس `http://localhost:8000`.

## افزودن یک مدخل

فایل دستهٔ مربوطه را در `data/<موضوع>/entries/` باز کنید و یک آبجکت اضافه کنید:

```json
{
  "id": "slug-انگلیسی-یکتا",
  "tags": ["lowercase", "english"],
  "related": ["id-مدخل-دیگر"],
  "fa": { "title": "…", "short": "…", "body": "<p>…</p>", "example": "<p>…</p>" },
  "en": { "title": "…", "short": "…", "body": "<p>…</p>" }
}
```

`fa` اجباری است؛ `en`، `example`، `svg` و `related` اختیاری‌اند. مدخلی که ترجمهٔ انگلیسی ندارد در حالت انگلیسی با متن فارسی و نشان «ترجمه نشده» نمایش داده می‌شود.

`id` در **کل سایت** یکتاست، نه فقط داخل یک موضوع — پس `related` می‌تواند بین موضوع‌ها لینک بدهد.

دسته و موضوع فیلد نیستند: دسته از نام فایل می‌آید و موضوع از نام پوشه.

## افزودن یک دسته

فایل جدید در `data/<موضوع>/entries/` بسازید و یک سطر به `data/<موضوع>/categories.json` اضافه کنید. ترتیب همان ترتیب آرایه است.

## افزودن یک موضوع

پوشه‌ای با `categories.json` و `entries/` بسازید و یک سطر به `data/topics.json` اضافه کنید:

```json
{ "id": "security", "fa": "شبکه و امنیت", "en": "Networks & Security" }
```

`id` باید نام پوشه باشد. با دو موضوع یا بیشتر، ردیف فیلتر موضوع و سرتیترها خودشان ظاهر می‌شوند.

**هیچ‌کدام از این کارها فایل JS را دست نمی‌زند.**

## قبل از انتشار

```bash
node --test
```

و `#/self-test` را باز کنید — هر مدخل را در هر دو زبان رندر می‌کند و خطاهای رندر، خطاهای اعتبارسنجی و مدخل‌های بدون ترجمهٔ انگلیسی را گزارش می‌دهد.

## ساختار

```
index.html            اسکلت صفحه
serve.js              سرور استاتیک محلی، بدون وابستگی
assets/css/style.css
assets/js/
  data.js             لود و اعتبارسنجی — بدون DOM
  i18n.js             زبان جاری و رشته‌های رابط
  search.js           فیلتر جستجو و هشتگ — خالص
  router.js           مسیریابی hash — خالص
  render.js           ساخت DOM — بدون fetch، بدون بستن رویداد
  app.js              حالت و اتصال؛ تنها فایلی که رویداد DOM می‌بندد
data/
  topics.json
  <topic>/categories.json
  <topic>/entries/*.json
test/                 تست واحد سه ماژول خالص (node --test)
```

## محدودیت‌ها

بدون فریم‌ورک، بدون npm، بدون مرحلهٔ build. بدون میزبان خارجی — نه CDN، نه فونت آنلاین، نه تصویر ریموت. دیاگرام‌ها SVG درون‌خطی‌اند.
